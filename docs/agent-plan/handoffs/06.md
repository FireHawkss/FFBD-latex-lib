## Result

`tikzffbd-planner.lua` exports `plan(Regions, Metrics, Constraint[], Frame) -> Plan[] | nil, Diagnostic[]`. It returns up to eight deterministic candidates, ranked by strong constraint cost, structural cut cost, page cuts, and row use. Hard column limits, exact row breaks, row/page keep-together, measured primary extent, and multipage estimated height are feasibility gates. Soft row breaks and columns are scored. Rows carry ordered semantic node and region IDs, `direction_sign`, hard `forced_break_ids`, soft `preferred_break_ids`, and estimated footprint. Rightward and downward layouts use the same primary/cross-axis calculation; row signs alternate and reset on each page. No scale is changed.

The row search keeps at most 12 partial plans per prefix and at most eight final candidates. Its expansion budget is `max(4096, node_count * 12 * 16)`. `Plan.estimated_costs` records the budget, evaluated expansions, exhaustion flag, route/row spacing allowances, and counts pruned for width, columns, hard breaks, group keeping, beam limit, budget, and page fit. Actual node metrics determine footprints; annotation and structure header metrics add a conservative global allowance. Semantic page cuts favor boundaries outside recognized parallel regions. Unresolved generic regions retain layered node order without an invented split/join pairing.

`Regions.flows` is an additive list of `{id, source, target, kind}` supplied by `tikzffbd-analysis.lua`; it lets the planner identify every flow crossing a page boundary. Each crossing has reciprocal `@continuation/.../out` and `/in` IDs in `page.continuation_ids` and detailed `page.continuation_markers`. Markers carry `semantic_flow_id`, `counterpart_id`, `role`, `text_ref`, and a plain `Continued: <flow ID>` label. The ordinal in a marker ID is the crossing order for that semantic flow, independent of coordinates and page numbers. Feedback direction determines which marker is incoming or outgoing. The future text registry/rendering phase must register and measure the generated `text_ref` before creating a Scene.

## Known limits and risks

Footprints are conservative estimates, not final geometry. The global annotation/header allowance may reject some layouts that could fit after precise placement. Continuation marker boxes and multiple simultaneous continuation labels are not yet measured, so part 07 and the solver must recheck page bounds and request a new plan if their geometry exceeds the frame. Generated continuation `text_ref` values are not yet registered in the TeX text registry. Single-page overflow is a warning with landscape, multipage, and explicit-scale recommendations; the planner does not silently resize or paginate. The legacy drawing pass remains active until integration.
