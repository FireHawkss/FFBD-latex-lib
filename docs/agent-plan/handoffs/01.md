## Result

`tests/contract_schema.py` exports `validate(kind, value) -> list[str]`,
`validate_trace(trace) -> list[str]`, and `canonical_trace(trace) -> str`.
Supported kinds are `Spec`, `Metrics`, `Frame`, `Constraint`, `Diagnostic`,
`Regions`, `Plan`, `Geometry`, `Routes`, and `Scene`. The validators enforce
required fields and types, integer scaled-point geometry, finite positive
scale, stable ID namespaces, declaration indices, reciprocal cross-page
continuations, orthogonal nonzero path segments, the seven-component quality
vector, and one environment ID per trace. Errors contain field paths.
`canonical_trace` emits deterministic, single-line UTF-8 JSON after validation.

User IDs are `[A-Za-z][A-Za-z0-9._-]*`. Internal IDs use `@namespace/segment`
with namespaces `flow`, `branch`, `join`, `port`, `continuation`, `region`,
`text`, and `constraint`. Generated IDs depend on deterministic command
expansion order; they must not depend on geometry. A command's declaration
index can occur on multiple flows expanded from the same branch/join.
Split/join nodes and their branch/join records share `@branch/...` or
`@join/...` connector IDs; user-authored function and terminal nodes keep user
IDs.
`CONTRACTS.md` records the trace envelope, object shapes, and renderer mock
fields. Schema validation is structural; it is not a solved-scene geometry or
visual-quality certification.

The fixture IDs are `basic-chain`, `complex-branches`,
`structures-feedback`, `custom-down`, `drone-real-world`, `chain-8`,
`branches-15-unequal`, `branches-30-unequal`, `joins-feedback-42`,
`dense-text-conditions`, `group-across-wrap`, `columns-hard-conflict`,
`columns-soft`, `rowbreak-hard-soft`, `annotations-eight`, `scale-explicit`,
`large-64-single`, `large-64-multipage`, `irregular-gap-adversary`, and
`displaced-label-adversary`. The first five point to the current TeX examples;
the rest specify successor cases for later parts. No prototype coordinates
are recorded as expected output.

cannot establish semantic graph validity, block/label clearance, page bounds,
or visual quality of a solved diagram. Those need the later phase checkers and
rendered references. The mock Scenes supply structural renderer input only.
