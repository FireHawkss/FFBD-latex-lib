## Result

`tikzffbd-renderer.lua` exports `render(Scene, text_registry, styles) -> TeX
material` and `styles_from_spec(Spec) -> styles`. `styles` contains ID-keyed
`nodes` and `structures` records from the Spec. An optional `text_registry`
is an ID-presence map; when supplied, every used reference is checked. TeX
tokens are retrieved only by `\ffbdTextByRef{ref}` at typesetting time.

The emitter sorts ID-keyed objects for deterministic output and preserves
ordered annotations, labels, and continuation markers. It emits each exact
rectangle and each ordered flow point in integer sp. The TeX macros draw group
backgrounds, flows, nodes, then group text, notes, edge labels, and
continuation text. Each page is a separate TikZ picture in normal TeX flow.
The completed picture is boxed and scaled once with `\scalebox` using the
Scene's explicit scale. No page width enters the renderer.

The package loads the renderer and its TeX macros, but the `ffbd` environment
still calls the legacy drawing pass. Part 11 must connect the bridge's sealed
Spec/Metrics/Frame to the part 09 solver and call `render` while the environment
text registry is live. This preserves the current examples while part 09's
visual acceptance remains open.

## Contract changes

None. The renderer consumes version 1 Scene fields without changing their
meaning. `styles_from_spec` is a convenience adapter for the existing Spec.

## Known limits and risks

- The `ffbd` environment currently displays the prototype drawing pass; it
  does not yet call the solver/renderer. Reproduce with `examples/basic.tex`.
- Scene version 1 gives group rectangles and text refs but no group header/info
  text rectangles. The TeX renderer places those at a 1 pt inset in the group
  rectangle; exact header/info geometry should be added if visual review finds
  a conflict.
- Continuation text refs must be registered and measured before solving and
  remain in the TeX registry through rendering. The bridge does not yet create
  generated continuation refs in ordinary `ffbd` compilation.
