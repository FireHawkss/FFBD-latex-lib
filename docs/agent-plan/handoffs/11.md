## Known limits and risks

- `lualatex -no-shell-escape -interaction=nonstopmode -halt-on-error -output-directory=/tmp examples/complex.tex` fails `solver-budget-exhausted`; the last conflict is `edge-label-conflict` on `@flow/18/2`.
- The same command on `examples/customization.tex` fails `edge-label-conflict` on `@flow/6/1`.
- The same command on `examples/structures.tex` fails `group-intrusion` because a nonmember enters a provisional group rectangle.
- `examples/basic.tex` renders with a one-node first row and reversed second row; its planner score does not yet penalize this enough to choose a clearer candidate.
- `examples/large-multipage.tex` prints a continuation marker containing an internal flow ID. Generated marker wording should be reader-facing, while preserving stable semantic linkage.
- The legacy TeX command and measurement helpers are still loaded; they include options whose values do not affect the solved layout (`wrap`, `column-sep`, `row-sep`, `port-stub`, and `scale-to-fit`). They should be retired or implemented before a stable release.
