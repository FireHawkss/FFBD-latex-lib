## Result

`tikzffbd-placement.lua` exports `place(Plan, Spec, Metrics, Constraint[]) -> Geometry | nil, Diagnostic`.
It checks environment identity, hard plan constraints, node coverage, measured
sizes, row footprints, node overlap, group containment, nonmember intrusion,
and hard multipage bounds. The latter uses additive
`Plan.estimated_costs.usable_primary_sp` and `usable_cross_sp` fields from the
planner. A conflicting candidate returns a Diagnostic and should be replaced
with another plan.

Each row uses longest forward-path layers. Long edges appear as virtual
segments for crossing evaluation, without changing Spec. Parallel arm order
comes from structural analysis. Deterministic barycenter sweeps and strict
improvement swaps reduce crossings. Measured layer widths, shared route gaps,
shared branch lane gaps, and shared row gaps assign integer-sp rectangles.
Signs reverse the primary axis on alternating rows; page starts retain the
planner's reset sign. Group rectangles contain measured members, header and
info width allowances, and a shared padding. Multipage groups have one
provisional rectangle per page.

Geometry contains `node_rects_by_id`, `group_rects_by_id`, `row_axes`,
`reserved_channels`, `provisional_ports`, and `spacing_stats` as required by
version 1. Additive fields are `group_boundary_ports`,
`group_rect_page_by_id`, and `page_extents_by_index`. Channels identify row
routes, wraps, feedback, annotations, joins, and long edges. Port records
name candidate sides, including serpentine direction and structure crossings.
Spacing stats include the shared gaps, crossing counts before/after ordering,
and gap variance. These are candidate geometry, not final routes.

## Known limits and risks

`place` receives no Frame under the shared interface. Hard multipage bounds
are checked when the Plan carries the new usable dimensions; manually built
plans without those fields cannot receive that check. Provisional group
rectangles include measured header dimensions and info width, but exact
header/info text positions belong to a later phase. Continuation
marker boxes and annotations remain unmeasured at this phase, so later
candidate evaluation must recheck complete page bounds. Barycenter ordering
uses a bounded heuristic and does not guarantee minimum crossings. A group
whose bounding rectangle would include a nonmember returns `group-intrusion`;
the planner may need another row candidate to resolve it.
