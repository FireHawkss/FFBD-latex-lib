## Result

`tikzffbd.sty` requires LuaLaTeX and loads the colocated Lua modules through
`kpse.find_file`. Each `ffbd` environment gets an `env-N` ID, a fresh model
builder, a TeX token registry, and a Metrics table. Existing commands also
feed the Lua builder while the prototype renderer remains in use. At environment
end, `tikzffbd_bridge.last` contains `{Spec, Metrics, Frame, diagnostics}`.
`Spec` is sealed by `tikzffbd-model.lua`; `Metrics` and `Frame` use integer sp.

The Lua module exports `begin`, `text`, `node`, `flow`, `feedback`,
`branch_begin`/`branch_arm`/`branch_end`, `join`, `structure`, `annotation`,
`row_break`, the three object-metric setters, and `finish`. These are bridge
entry points used by `tikzffbd-bridge.code.tex`. Original tokens stay in
`\l__ffbd_text_registry_prop`, keyed by `@text/env-N/ordinal`; the renderer can
retrieve them with `\ffbdTextByRef{ref}` while its environment is active.
Lua receives only the ref and measured dimensions. Refs are unique across
environments and the registry is cleared at each start.

Public syntax added: `scale=<positive number>`, `multipage=true|false`,
`max-columns-strength=hard|soft`, `\endrow[soft]` (bare form is hard), and
`\annotation[type=Risk,position=top-left,position-strength=soft]{id}{body}`.
The other seven positions from `CONTRACTS.md` are accepted. Legacy
`\annotation[Risk]{id}{body}` and the three mandatory arguments remain valid.
Node, connector, condition, annotation, and structure text is measured in the
TikZ style used by the current drawing pass. A repeated styled-node box in the
fixture matches `Metrics.by_node_id` within 1 sp; the expected tolerance for
the same TeX box and style is 1 sp. Text metrics include the selected styled
item's footprint; annotation metrics include its combined type and body.

passed 9 tests. No Overleaf upload was performed in this session.

## Known limits and risks

The old renderer still draws the diagram. It does not yet apply `scale`,
`multipage`, soft column/row preferences, or explicit annotation positions;
those are captured for the solver and renderer parts. `scale-to-fit` remains
an explicit legacy option, but its default is now false so ordinary compilation
does not silently shrink a diagram. The 1 sp measurement comparison covers a
styled function box; an Overleaf run and broader typography comparisons remain
for integration part 11.
