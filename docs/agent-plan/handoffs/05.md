## Result

`tikzffbd-analysis.lua` exports `analyze(spec) -> Regions`. The input is a
sealed, valid Spec. It reads only `forward` flows for the DAG, computes a
stable lexical tie-broken topological order, and recognizes a branch/join
pair only when every declared branch arm reaches one nearest common join,
arm interiors do not overlap or leak, the join has one incoming flow from
each arm, and connector logic agrees. Nested parallels are represented in
arm sequence children. `parallel.ordered_children` follows branch arm order;
each child sequence retains its member order. The root sequence covers every
semantic node once. Sequence leaves and parallel regions carry member,
entry, and exit IDs. Region IDs are derived from semantic IDs, never layout.

Structures are `group` regions listed in `group_region_ids`. They retain the
author's member order, declared input and output member order, style, and all
cross-boundary flow IDs and member endpoints. They are overlays because a
valid group may cross a parallel boundary. Feedback remains separate from
the forward DAG in `feedback_links`, with source and target node IDs and
containing parallel/group region IDs.

An unresolved split or join creates an `ambiguities` record with a reason and
a `generic` region listed in `fallback_subgraphs`. Its `member_ids` are in
forward topological order and `flow_ids` preserve the actual forward edges.
Part 06 should inspect `fallback_subgraphs` and use general layered placement
for those members; it must not infer a split/join match from the root's leaf
sequence. Additive `forward_order` and `group_region_ids` fields make this
explicit without changing the version 1 contract.

## Known limits and risks

Regions for unresolved connectors are overlays on the root sequence. Part 06
must use the fallback records to avoid treating their leaf sequence as a
resolved branch layout. A group crossing a parallel boundary is also an
overlay and needs explicit containment treatment in later placement. Generic
fallback conservatively includes all forward-reachable nodes after an
unresolved split; it may be broader than the smallest ambiguous subgraph.
